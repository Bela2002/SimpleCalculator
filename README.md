# 🧮 SimpleCalculator

A clean and responsive calculator built using **HTML**, **CSS**, and **JavaScript** 🖥️📱  
Perform basic arithmetic operations with a user-friendly interface that works beautifully across all devices!

---

## 🚀 Overview

This project is a simple yet functional calculator designed for quick and accurate calculations.  
It demonstrates core front-end development skills such as:

- ✅ DOM Manipulation  
- ✅ Event Handling  
- ✅ CSS Styling & Layout Design  

---

## ✨ Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🎯 Responsive Layout (Desktop + Mobile)  
- 🎨 Clean & Intuitive User Interface  

---

## 🛠️ Tech Stack

- 🧱 **HTML** – Structure  
- 🎨 **CSS** – Styling and responsive layout  
- ⚙️ **JavaScript** – Logic and interactivity

## 📱 Responsive Design

The calculator layout adjusts gracefully for different screen sizes, ensuring a smooth experience whether you're using a computer, tablet, or phone.
